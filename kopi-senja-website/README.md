# Kopi Senja — Website Portofolio

Website landing page kafe fiktif untuk latihan dan portofolio desain website.

## Isi folder
- `index.html` — struktur halaman
- `style.css` — tampilan, warna, layout, dan responsif
- `script.js` — navigasi mobile, tahun otomatis, dan tautan WhatsApp

## Cara melihat di komputer
1. Ekstrak file ZIP.
2. Buka folder `kopi-senja-website`.
3. Klik dua kali `index.html` untuk membukanya di browser.

## Sebelum dipublikasikan
- Ganti nomor WhatsApp `6281234567890` di `script.js` dengan nomor milik bisnis/nomor demo yang kamu kendalikan.
- Ganti alamat, email, Instagram, jam buka, menu, dan harga contoh di `index.html`.
- Foto saat ini dimuat dari Unsplash melalui internet. Koneksi internet diperlukan untuk menampilkannya.
- Pastikan kamu memiliki hak untuk memakai foto dan identitas merek yang digunakan jika website dipakai untuk bisnis sungguhan.

## Publikasikan dengan GitHub Pages
1. Masuk ke https://github.com dan login.
2. Klik tombol **New repository**.
3. Isi nama repository, misalnya `kopi-senja`.
4. Pilih **Public**, lalu klik **Create repository**.
5. Klik **Add file → Upload files**.
6. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` (unggah isi folder, bukan file ZIP).
7. Klik **Commit changes**.
8. Buka **Settings → Pages**.
9. Pada **Build and deployment**, pilih **Deploy from a branch**.
10. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
11. Tunggu proses publikasi. URL website biasanya berbentuk `https://USERNAME.github.io/kopi-senja/`.

Jika halaman belum muncul, tunggu beberapa menit lalu refresh halaman GitHub Pages.
